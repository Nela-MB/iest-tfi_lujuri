# Matriz de selección de herramientas de IA (Anexo I)

> Se eligieron las herramientas que la estudiante ya tiene disponibles. Los planes y límites cambian seguido: antes de usar cada una hay que **verificar en la cuenta propia** qué incluye el plan y si permite uso comercial de lo generado.

| Uso | Herramienta y modelo | Empresa y plan | Motivo de la elección | Riesgos y mitigación |
|---|---|---|---|---|
| Programación | Agente del chat de VS Code (GitHub Copilot). Anotar el modelo que figure al usar | Microsoft / GitHub. Plan: anotar el de la cuenta | Está integrado al editor, lee `AGENTS.md` y los comandos `/spec`, `/clarificar` y `/verificar`, y trabaja sobre los archivos del proyecto | Puede escribir código que no se entiende o inseguro: se lee cada cambio antes de aceptarlo, tests primero y un commit por tarea |
| Specs, planes, guiones e informe | Claude (chat). Anotar el modelo que figure al usar | Anthropic. Plan gratuito | Ayuda a redactar y revisar specs en EARS, tablas y guiones con criterio claro | Puede inventar datos o contradecir los `docs/`: se revisa contra la constitución y se decide cada punto |
| Imágenes | ChatGPT (generación de imágenes) y Gemini (generación de imágenes). Anotar el modelo | OpenAI y Google. Planes gratuitos | Dos herramientas permiten comparar resultados y repetir si una agota su límite | Manos o rostros deformados, textos ilegibles o estereotipos: se revisan con la Tabla 3 del TFI y se documenta una corrección |
| Video (clips) | Canva (video con IA). Gemini con Veo, solo si la cuenta lo habilita | Canva y Google. Plan gratuito | Canva permite generar clips y editarlos en el mismo lugar; los créditos de IA gratuitos son limitados | Pocos créditos y clips cortos: se planifica el guion antes de generar y se registra cuántas piezas se hicieron y cuántas se usaron |
| Edición de video | Canva (editor de video) | Canva. Plan gratuito | Permite montar clips, subtítulos, música y exportar sin instalar programas | Marcas de agua o elementos premium no disponibles: usar solo elementos libres de uso |
| Voz | Voz propia de la estudiante para la demo; para el spot, voz propia o la herramienta que se verifique | — | Evita generar la voz de una persona real y no depende de cuotas | Si se usa voz sintética: confirmar licencia y declararlo en la ficha |
| Música y sonido | Biblioteca de audio de Canva (licenciada) | Canva. Plan gratuito | Está integrada al editor y tiene licencia clara | Algunas pistas son premium: elegir las gratuitas y anotar la licencia |
| Gráficos | Claude o ChatGPT para escribir el código (Chart.js o Python), con datos reales del repositorio | Anthropic y OpenAI. Planes gratuitos | Genera el código del gráfico; los datos salen del historial de commits y de las tareas | Inventar datos es falta grave: cada dato se verifica en el repositorio |
