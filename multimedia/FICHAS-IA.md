# FICHAS-IA: una ficha por cada pieza generada con IA

> Se completa una ficha por imagen, video o gráfico (Anexo III del TFI). Las piezas que se descartan también se cuentan en el registro de abajo.

## Registro de piezas (alimenta un gráfico del informe)

| Tipo | Piezas generadas | Piezas usadas |
|---|---|---|
| Imágenes | 0 | 0 |
| Clips de video | 0 | 0 |
| Gráficos | 0 | 0 |

> Actualizar los números cada vez que se genere o se descarte una pieza.

## Plantilla de ficha

| Campo | Contenido |
|---|---|
| Nº y nombre de la pieza | Ej.: Figura 1. Portada del sitio (hero) |
| Tipo | Imagen / video / gráfico / voz / música |
| Herramienta y modelo | Nombre, versión y fecha de uso |
| Prompt final | Texto completo del prompt que dio el resultado elegido |
| Iteraciones | Cantidad de intentos y qué se corrigió en cada uno |
| Edición humana | Recortes, retoques, color, montaje o textos agregados |
| Uso en el proyecto | Página, sección, video o informe donde aparece |
| Licencia | Condiciones de uso de la herramienta y si permite uso comercial |
| Leyenda de transparencia | «Imagen generada con IA (herramienta) y editada por la autora» |
